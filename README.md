# Digital Will AI

Secure digital asset inheritance platform with zero-trust emergency access controls.

## Project structure

- backend/: Express.js API with MongoDB, security middleware, and future auth/RBAC flows
- backend/models/: Mongoose schemas for users, assets, nominees, emergency requests, and audit logs
- backend/utils/: Encryption and explainable risk-engine helpers for the security workflow
- frontend/: React + Vite + Tailwind client for the demo experience

## Current scaffold status

- Backend server shell with rate limiting and health endpoints
- Frontend Vite shell with Tailwind styling
- Initial security models and utilities for encryption, risk scoring, and audit logging

## Getting started

1. Install dependencies with `npm run install:all`
2. Start the local stack with `npm run dev`
3. Open the frontend at `http://localhost:5173` and the API at `http://localhost:5000`
